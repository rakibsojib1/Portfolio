## 🎨 Design Features

| Feature | Description |
|---|---|
| 🌌 **Animated Background** | 4 drifting radial-gradient orbs + floating particle canvas |
| 🔵 **Profile Orb** | 3 rotating ring animations with glow border around photo |
| 🏷️ **Floating Chips** | Flutter · AI Video · Telegram · 🇧🇩 Bangladesh chips |
| 🔢 **Animated Counters** | Numbers count up when scrolled into view |
| ✨ **Gradient Text** | Animated purple → violet → cyan gradient on key words |
| 🖱️ **Mouse Glow** | Radial cursor glow follows the mouse |
| 🌗 **Dark / Light Mode** | Full theme switcher with localStorage persistence |
| 📱 **Fully Responsive** | Mobile-first: 2-col grids on phone, optimized at every breakpoint |
| 🎬 **Scroll Reveal** | All sections animate in on scroll via IntersectionObserver |

## 📱 Mobile Responsive

The portfolio is optimized for all screen sizes:

- **Desktop (1100px+)** — 2-column hero, 3-col service/project grids
- **Tablet (768–1100px)** — Centered hero, 2-col cards
- **Phone (480–768px)** — 2-col button grid, horizontal counters, 2-col service & project cards
- **Small phone (< 360px)** — Single column fallback

## 🏃 Run Locally

Just open `index.html` in your browser — no build step needed!

```bash

# or
python -m http.server 5500
```

Then visit `http://localhost:5500`
